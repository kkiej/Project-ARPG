# a000 通用动作标注（仅已确认项）

> 范围：仅 `a000` 前缀（单手/双武器·轻型姿态，也是手势/翻滚/死亡/环境交互的承载前缀）。
> 原则：**只填已确认的动作**，未确认的（如 locomotion 走/跑基址、死亡、环境交互的具体槽位）暂不列。
> 其它姿态前缀（`a002`/`a010`/`a013`…）待后续单独成表。
>
> **编码规则**（权威：`ER-Animation-Category-Reference.md` §6.0）：
> ```
> animId = stance * 1_000_000 + (actionBase + load*10 + direction)
> ```
> `a000` 的 stance=0，故 **animId == 六位后缀本身**（如 `a000_027100 → 27100`）。
> - 负重 load：轻=0 / 中=10 / 重=20（十位，仅 3 档）。
> - 方向 direction：前=0 / 后=1 / 左=2 / 右=3（个位）。
>
> 对应代码：`CommonAnimationConvention`（`rollBase=27100`、`backstepBase=27000`）、`CommonAnimationConvention.ComposeId(0, base, load, dir)`。
> 置信度：✅=权威表明确；🔶=社区 ID 表（手势）。

## 备注：翻滚第二组 027104–027107

> 结论（基于 `TAE_Events/a00.json` 实测对比 `a000_027100` vs `a000_027104`）：

- **机制上等同标准前滚**：两者 TAE 事件脚本几乎完全一致——相同总时长(~2.0s+落地)、相同武器破风音(430)、相同身体/布料脚步音(100240/100360)、相同落地尘土 FFX、相同的一大批行为标志事件、相同的恢复输入窗(`SetPlayerInput` 100/102 @0.33–0.53)。i-frame / 恢复 / 取消窗一致。
- **差异不在 TAE**：肉眼可见的动作差异几乎全在 **clip 关键帧本身**（TAE 不存姿态）。TAE 层仅有的微小差异是 `027104` 尾部多了几条后续输入窗(`SetPlayerInput` 输入码 2001/3001/6200)+ `PlaySFX_Body`，暗示它是**备用 / 特定衔接语境下的前滚**，而非机制不同的另一种闪避。
- **触发条件未知**：选哪个 clip 由 HKS / 行为图决定，不在 TAE 内（该文件本仓库没有），无法从 TAE 确认 `027104` 的确切触发条件。
- **项目处理**：`027104–107` 视为 `027100–103`（权威四向集）的冗余/备用前滚，**先不接**；回填器与正式标注仍用 `027100–103`。
