## 0. 一页纸提案 (One-Pager)

### 0.1 Logline (一句话定位)

> **一款融合只狼弹反手感、类魂战斗深度、死亡细胞 Roguelite 循环的东方意境单人 3D 动作游戏。**

### 0.2 Elevator Pitch (30 秒电梯演讲)

> 你是一名失去主家的浪人,在大雪封山的孤村醒来。每次出门寻仇都会死,但带回的"残念"会在村中累积,解锁新的招式、武器和路径。游戏的核心是**弹反 → 破势 → 处决**的精确战斗,辅以每次跑图随机变化的房间布局、武器词缀和 Buff 流派。死亡是叙事的一部分,而不是失败。

### 0.3 关键参数

| 项 | 值 |
|---|---|
| 平台 | PC (Steam) — 1.0 后考虑 Switch / PS5 |
| 视角 | 第三人称 3D |
| 时长 | 单次跑图 30-60 分钟 / 通关 15-25 小时 / 内容上限 50-80 小时 |
| 模式 | 纯单机 |
| 价格 | EA $14.99 / 1.0 $19.99 |
| 引擎 | Unity 6 + URP |
| 团队 | 1 人(TA + 程序),外包音乐与配音 |
| 上线计划 | 垂直切片 6 个月 / EA 24 个月 / 1.0 36 个月 |

### 0.4 USP (Unique Selling Points)

1. **只狼级别的弹反战斗 + Roguelite 的快节奏循环** — 市面空位
2. **东方水墨意境的 3D 美术** — TA 出身的视觉锚点
3. **程序化生成 + 手工关卡混搭** — 重复但不重样
4. **每件武器都是一个流派** — 不是数值堆叠,是动作差异
5. **死亡推进叙事** — 类似 Hades 的渐进式故事揭示

## 1. 设计支柱 (Design Pillars)

> 每个设计决策必须能追溯到至少一个支柱。冲突时按以下优先级处理:

| # | 支柱 | 含义 | 反面教材 |
|---|------|------|----------|
| 1 | **精准的弹反对垒** | 战斗的核心快感来自时序判断,而非数值堆叠 | 暗黑3 数值滚动 |
| 2 | **重复但不重样** | 关卡 / 武器 / Build 每次都不同,但操作肌肉记忆稳定 | 纯随机房间 |
| 3 | **死亡是开始,不是结束** | 死亡惩罚轻,但每次死亡都有持久回报 | 类魂 1 代失魂 |
| 4 | **少即是多** | 武器/敌人/Boss 都精雕,而非堆量 | 育碧公式开放世界 |
| 5 | **静谧而克制的氛围** | 东方留白美学,镜头/音效都内敛 | 现代美式 ARPG 浮夸 |

## 2. 核心循环 (Core Loop)

### 2.1 宏观循环 (Meta Loop)

```
醒来于孤村 (Hub) ─────────────────────────────────┐
        │                                          │
        │ 与 NPC 对话 → 推进碎片化剧情              │
        │ 用残念解锁 → 新武器/护身符/路径          │
        │ 在道场练习 → 试招式 / 调整 Build         │
        ▼                                          │
出门(选择 3 条分支之一)                            │
        │                                          │
        │ 雪山 / 竹林 / 火场 三主题分支             │
        │ 难度递增 / 奖励递增 / 主题不同            │
        ▼                                          │
进入第 1 区域 (5-7 个房间)                         │
        │                                          │
        │ 战斗房 × 3 / 商店 / 谜题 / 奖励          │
        │ 拾取武器 Affix / Buff 卡牌               │
        ▼                                          │
区域 Boss 战                                       │
        │                                          │
        │ 弹反对垒 → 体干破 → 处决                 │
        │ 击败 → 解锁下一区域 / 死亡 → 回到 Hub    │
        ▼                                          │
区域 2 → 区域 3 → 最终 Boss                        │
        │                                          │
        ▼                                          │
死亡 / 通关  → 回 Hub,携带 ─────────────────────┘
              "残念"(永久资源) + 解锁记录
```

### 2.2 微观循环 (Moment-to-Moment)

```
观察敌人姿势 → 预判攻击 → 弹反 / 闪避 / 招架
       │
       └─ 弹反成功 → 体干槽推进 → 进入处决距离 → R 键处决
       └─ 闪避成功 → 反击窗口 → 普攻连段
       └─ 招架成功 → 反伤 → 短硬直
       └─ 失误 → 受伤 → HP 减 / 自我治疗(消耗 1 次回药)
```

**核心节奏**:每场战斗 30 秒 - 2 分钟,Boss 战 5-15 分钟。

## 3. 战斗系统

### 3.1 输入模板

| 按键 (键盘 / 手柄) | 动作 |
|---|---|
| WASD / 左摇杆 | 移动 |
| 鼠标 / 右摇杆 | 视角 |
| Space / A | 翻滚(无敌帧)/ 跳跃 |
| Shift / B(长按) | 冲刺 / 钩绳(后期解锁) |
| 左键 / RB | 轻攻击 |
| 右键 / RT | 重攻击(可蓄力) |
| Q / LB | **弹反 / 招架**(核心键) |
| E / LT | 忍义手 / 副手能力 |
| F / Y | 互动 / 处决 |
| R / X | 喝药 |
| Tab / Select | Build 面板 |

### 3.2 三大状态值

| 状态 | 玩家 | 敌人 | 恢复方式 |
|---|---|---|---|
| **HP**(生命) | 失败条件 | 失败条件 | 喝药(限次) |
| **体干**(Posture) | 满了破势硬直 | 满了破势 → 可处决 | 时间恢复(站立快) |
| **集中**(Focus) | 释放绝技 | 部分敌人有 | 弹反 / 完美闪避 |

### 3.3 弹反系统(核心机制)

```
敌人攻击释放
     │
     ▼ ───────────────────────────────────────────────
     ▼  弹反窗口(0.15s)│  招架窗口(0.10s)
     ▼ ─────────────────┴──────────────────────────────
玩家按 Q
     │
     ├─ 弹反 (Parry):金光 + 大体干伤害 + 玩家集中 +1
     ├─ 招架 (Block):无伤但消耗体力,敌人轻硬直
     └─ 太早/太晚:吃满伤
```

**设计参数**(待平衡):
- 弹反窗口 9 帧(0.15s @ 60fps)
- 招架前摇 3 帧,后摇 6 帧
- 弹反对敌人造成自身武器伤害的 0.4× 倍体干伤害
- 连续弹反不衰减(鼓励对垒)

### 3.4 攻击类型与处理

| 攻击类型 | 视觉提示 | 应对方式 |
|---|---|---|
| 普通攻击 | 无 | 弹反 / 闪避 / 招架 |
| **危**(下段) | 红光 + 长鸣 | 必须跳跃(踩头反击) |
| **危**(突刺) | 红光 + 短鸣 | 必须看破(向前 Q,反伤) |
| **危**(投技) | 红光 + 蹲身 | 必须翻滚或跳跃后闪 |
| 蓄力重击 | 紫光 | 弹反窗口减半,奖励翻倍 |

### 3.5 处决系统

体干破 → 敌人跪地 → 玩家进入处决距离按 F → 播放处决动画 → **必杀**(普通敌人) / **拔除一缕魂**(Boss 多缕)

- 处决期间无敌
- 处决回 30% 体力 + 1 缕"残念"
- Boss 通常需要 2-4 次处决

### 3.6 技能与忍义手

| 主手武器 | 副手忍义手 (E 键)|
|---|---|
| 太刀 / 双刀 / 苗刀(主流派) | 火筒 / 飞镖 / 钩绳 / 替身术 / 凿击锤 |

每次跑图随机带 1 主 1 副,死亡后保留解锁。

## 4. 武器与 Build 系统

### 4.1 武器框架

**武器 = 流派 + 词缀**

```
WeaponItem (SO,流派模板)
 ├── weaponAnimationSet (招式集)
 ├── basePhysicalDamage / basePoiseDamage / baseStaminaCost
 ├── weaponClass (Katana / TwinBlade / Naginata / NoDachi ...)
 └── 运行时生成的 Affix 列表 (随机词缀)
```

### 4.2 Affix 词缀系统(借鉴死亡细胞 + 暗黑)

每件武器有 **2-4 个随机词缀**,来自三大色卡:

| 色卡 | 主题 | 词缀示例 |
|---|---|---|
| **赤**(暴) | 高风险高回报 | "弹反追加燃烧 / 体力 < 30% 时伤害 +50% / 暴击概率 +15%" |
| **青**(稳) | 防御与续航 | "完美闪避回复 5% HP / 招架反伤 +30% / 弹反不消耗体力" |
| **紫**(技) | 异常状态与控制 | "三连击触发出血 / 处决回 1 集中点 / 蓄力期间无敌" |

**Synergy 设计**:每个武器有 1-2 个色卡偏向。整套 Build 凑齐 6+ 同色卡 → 解锁"色卡领域"(类死亡细胞终极效果)。

### 4.3 护身符 (Charm) 系统(替代死亡细胞 Mutation)

- 跑图中获得护身符(最多装 3 个)
- 提供**结构性 Buff**(改游戏规则),非纯数值
- 例:"招架不消耗体力 / 弹反窗口 +3 帧 / 每次处决减少药水冷却 1s"

### 4.4 流派示例(垂直切片需做 3 个)

| 流派 | 特点 | 节奏 | 适合 |
|---|---|---|---|
| **太刀** | 中速 / 中段 / 平衡 | ★★★ | 新手 / 弹反流 |
| **双刀** | 快速 / 短刃 / 连击 | ★★★★★ | 进攻流 / 出血 Build |
| **苗刀** | 慢速 / 长距 / 重击 | ★★ | 体干流 / 蓄力 Build |

1.0 目标:8 个流派。

## 5. 关卡设计

### 5.1 区域结构

```
分支 (Branch) — 3 条
  └─ 区域 (Region) — 每分支 2-3 个,共 8-10 个
       └─ 房间 (Room) — 每区域 5-7 个,程序化拼接
            └─ 关卡块 (Tile) — Houdini 生成的 prefab
```

### 5.2 程序化生成方案

```
┌─────────────────────────────────────────────────┐
│ Houdini 中生成:                                 │
│  ├── 30-50 个 prefab 房间模块(每个 ~5-15s 通过) │
│  ├── 每个房间 4 种变体(同布局,不同装饰/天气)   │
│  └── 烘焙为 .fbx + .png + .asset 三套资产       │
└─────────────────────────────────────────────────┘
                    │
                    ▼ (运行时,Unity 内)
┌─────────────────────────────────────────────────┐
│ RoomGenerator:                                  │
│  1. 按区域规则选 5-7 个房间类型(战斗/商店/谜题)│
│  2. 从对应类型池随机抽 prefab                    │
│  3. 拼接(房间出入口对齐)                       │
│  4. 撒敌人 / Affix / Buff                       │
│  5. 烘焙临时 NavMesh                            │
└─────────────────────────────────────────────────┘
```

### 5.3 房间类型分布(每个区域 5-7 个房间)

| 类型 | 比例 | 内容 |
|---|---|---|
| 战斗房 | 50% | 3-5 个敌人,小怪 + 1 个精英 |
| 谜题房 | 10% | 跳跃 / 解锁 / 隐藏路径 |
| 商店房 | 10% | 用残念购买武器 / 护身符 |
| 奖励房 | 10% | 高难度 + 高奖励(诅咒) |
| 休整房 | 10% | 篝火 / 回复 HP / 升级武器 |
| 叙事房 | 10% | NPC 对话 / 环境叙事 |
| **Boss 房** | 每区域末尾 1 个 | — |

### 5.4 主题与视觉锚点

| 分支 | 主题 | 视觉锚点 | 灯光 |
|---|---|---|---|
| **雪山道** | 雪 + 黑松 + 寺院 | 苇名风 | 冷蓝 + 暖灯笼 |
| **竹林径** | 竹 + 月光 + 倭城 | 浮世绘风 | 月色青 + 萤火 |
| **火场涉** | 焰 + 红叶 + 废墟 | 末日感 | 暖橙 + 烟雾 |

**TA 重点投入**:每个分支选择 1-2 个视觉锚点反复打磨(竹林的风、雪的踩踏、火的烟尘)。

## 6. 敌人与 Boss

### 6.1 小怪设计原则

| 类别 | 数量 | 设计目标 |
|---|---|---|
| **杂兵**(刀 / 枪 / 弓) | 4-6 种 | 教学弹反 / 闪避 / 看破 |
| **精英** | 2-3 种 | 中型 Boss,有红光攻击 |
| **特殊**(忍者 / 巫女) | 2-3 种 | 异常机制(隐身 / 召唤) |

**所有敌人共享** `AICharacterManager` + 状态机 SO,只通过 `AICharacterAttackAction` 列表区分。

### 6.2 Boss 设计(垂直切片 1 个,1.0 目标 8 个)

每个 Boss 需要:
- **3-5 个阶段** — 阶段切换有视觉/音效仪式感
- **独特机制** — 不只是"换招式",而是改变玩家行为(如:某 Boss 必须用钩绳上墙才能打)
- **多缕魂** — 需要 2-4 次处决(弹反对垒乐趣)
- **叙事意义** — 每个 Boss 都是主角过去某段经历的具象化

**Boss 名单草拟**(占位符,可改):

| # | 名字 | 主题 | 机制亮点 |
|---|---|---|---|
| 1 | **守墓人·寒** | 教学 Boss / 雪山入口 | 弹反节奏教学 |
| 2 | **百足众·黑** | 多人战斗 | 同时对付 3 个目标 |
| 3 | **巫女·缘起** | 法术战 | 必须破坏护盾再处决 |
| 4 | **天狗·朱雀** | 空战 | 钩绳上墙战斗 |
| 5 | **影武者·己** | 镜像战 | 复制玩家招式 |
| 6 | **赤鬼·终焰** | 巨型 Boss | 招式范围大,弹反时机严格 |
| 7 | **盲剑·虚白** | 速度战 | 极快攻击,音效是关键 |
| 8 | **真主·??** | 最终 Boss | 综合所有机制 |

## 7. Meta 进度 (永久解锁)

### 7.1 资源体系

| 资源 | 获得 | 消耗 |
|---|---|---|
| **残念**(灵魂碎片) | 击杀敌人 / Boss 处决 | 解锁武器 / 护身符 / 路径 |
| **遗物**(稀有掉落) | Boss 必掉 / 谜题房 | 解锁新流派 / 终极绝技 |
| **铜钱**(跑图内货币) | 击杀 / 拾取 | 房间内商店,**死亡后清零** |

### 7.2 解锁树(Hub 中道场看板)

```
道场看板
 ├── 武器流派 (8 个)
 │    ├── 太刀 (初始解锁)
 │    ├── 双刀  - 1 遗物 + 100 残念
 │    ├── 苗刀  - 1 遗物 + 200 残念
 │    └── ...
 ├── 忍义手 (12 个)
 │    └── ...
 ├── 护身符池 (40 个)
 │    └── 解锁后进入跑图掉落池
 ├── Affix 池 (200+)
 │    └── 同上
 ├── 起始装备槽(扩展)
 └── 道场 NPC 升级(更多对话 / 商店)
```

### 7.3 NewGame+ 设计

通关后开启**赤之朱印**(类只狼魔玲):敌人变强 + 新词缀池 + 隐藏 Boss。

## 8. 营地 Hub

### 8.1 Hub 是什么

一个**3-5 个主要区域**的小型场景,玩家在每次死亡 / 通关后回到这里。

```
孤村 (Hub)
 ├── 主屋     — 玩家床(标题画面)
 ├── 道场     — 解锁树 / 训练假人 / 试招式
 ├── 锻刀场   — 武器强化(用遗物)
 ├── 神社     — 重置 Build / 接取诅咒挑战
 ├── 茶屋     — NPC 对话 / 叙事推进
 └── 出门处   — 选择分支 / 出发
```

### 8.2 NPC 与叙事(Hades 模板)

每次回到 Hub,所有 NPC 都有 **1-2 句新对话**,推进碎片化剧情。

| NPC | 角色 | 主题 |
|---|---|---|
| **铁匠·阿白** | 武器升级 | 与主角是旧友 |
| **巫女·小雪** | 神社 / 重置 | 神秘女性,知道真相 |
| **盲歌人** | 试招式 | 道场陪练 + 哲学闲聊 |
| **店主·阿婆** | 商店 | 提供资讯与小道消息 |

**对话量**:1.0 目标 500-800 条短对话(每条 1-2 句)。

### 8.3 主线推进规则

- 击败 Boss N → 解锁 NPC N+1
- 死亡 X 次 → 解锁某段记忆
- 累计残念 → 主屋出现新物件(环境叙事)

## 9. 叙事与世界观

### 9.1 一句话设定

> **江户末年,主角是失主的浪人,前来雪山寻仇,却发现整座山被诅咒,死后又会醒在山下的孤村。** 真相是:这座山是亡者的"中阴"。

### 9.2 叙事手法

- **碎片化** — Hades 模式,死亡 = 一段对话 / 一个记忆
- **环境叙事** — 房间布局、尸骸位置暗示故事
- **NPC 多重身份** — Hub 的 NPC 其实都是亡者,但他们自己不知道
- **多结局**:
  - 普通结局:斩杀真主,但忘了一切
  - 真结局:与真主对话,放下复仇,化为残念守护下一位浪人
  - 暗结局:成为新的"真主"

### 9.3 关键叙事节奏

| 阶段 | 推进 | 解锁 |
|---|---|---|
| 死亡 0-3 次 | 玩家以为"我只是浪人" | 雪山入口 |
| 死亡 4-10 次 | 发现村民言语奇怪 | 竹林径 |
| 死亡 10-20 次 | 主角的记忆碎片 | 火场涉 |
| 死亡 20+ 次 | 真相揭开 | 最终 Boss / 多结局 |

## 10. 美术方向

### 10.1 关键词

**水墨意境 + 卡通渲染 + 留白构图 + 高对比度灯光**

### 10.2 参考作品 (Moodboard)

- 《对马岛之魂》— 风、草、构图
- 《只狼》— 战斗反馈、刀光
- 《Tunic》— 留白与提示
- 《GRIS》— 色彩情绪
- 《下一站江湖》— 中式 2.5D 氛围
- 浮世绘:葛饰北斋《富岳三十六景》

### 10.3 角色风格

- **比例**:写实身高,头部略大(7 头身,卡通化)

## 13. 技术架构

### 13.1 从 Project-ARPG 现状改造

**砍除**(单机化):
- `WorldGameSessionManager` + Steamworks + FacePunch
- `*NetworkManager` 中所有 RPC,改回 MonoBehaviour

**新增**:
- `RoomGenerator` — Houdini Prefab 池 + 拼接器
- `AffixSystem` — 武器词缀生成与挂载
- `MetaProgressManager` — 永久解锁 + 残念账户
- `RunStateManager` — 单次跑图临时状态(死亡清零)
- `NarrativeManager` — Hades 模式碎片化对话调度

**保留并打磨**:
- `KCCCharacterController` 移动手感
- `CharacterAnimatorManager` 多层 Animancer
- `AIState` SO 状态机(给 Boss 用)
- `WeaponItem` + `WeaponAnimationSet` SO
- `DamageCollider` + `Effect` 体系
- `RoleShaderManager` + Cluster Light + VolumetricFog

## 15. 风险评估

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| **弹反手感调不好** | 高 | 灾难 | M1 阶段先做 50 小时单一原型,只调手感 |

| **AI 平衡不够好** | 高 | 中等 | Roguelite 容忍度高,EA 阶段持续迭代 |
| **TA 出身,程序工期估错** | 高 | 严重 | 每阶段预留 30% Buffer |
| **个人开发者孤独崩溃** | 中 | 严重 | 加入独立开发者社区,定期分享进展 |
| **市场窗口期错过** | 低 | 中等 | 类魂市场长青,但每年盯 1-2 个直接竞品 |
| **资金断裂** | 中 | 灾难 | EA 上线作为关键现金流节点 |
